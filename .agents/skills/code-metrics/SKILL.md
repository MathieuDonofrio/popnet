# Code metrics

Follow the [tool guide](../../../tools/code_metrics/README.md). Report the measured directories, source line count, Cognitive Complexity percentile and value, and file and function counts.

Use these figures as rough observations about size and structure over time. Correctness, clarity, maintainability, and performance come first. Avoid routine collection, quality gates, and changes made solely to lower the numbers.
