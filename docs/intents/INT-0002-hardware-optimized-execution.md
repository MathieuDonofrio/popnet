id: INT-0002
title: Efficient tensor execution across CPUs and GPUs
---

## Problem

Different CPUs and GPUs offer different capabilities for accelerating tensor operations.

## Desired outcome

Run tensor operations efficiently on supported hardware architectures.

## Scope

Backend execution and architecture-specific optimization of library code and kernels.

## Success assessment

Assess whether architecture-specific optimizations improve execution efficiency by benchmarking representative operations and tensor shapes against comparable baselines on supported hardware configurations.
